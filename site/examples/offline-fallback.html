Optimistic send, offline fallback

One on-click renders the message optimistically and then sends it in the same chain (#list.render({…}); #form.send()). The row rolls back on any failure: on-request-error, on-request-timeout and on-request-offline each run #list.undo(). On this static site that is a missing endpoint with the network on (request-error), or a network failure with it off (request-offline).
