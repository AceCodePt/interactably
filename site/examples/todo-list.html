A to-do list that survives reload

This is a small application-shaped page on a static host: the sample list is a real GET of site/fragments/todos.html, while adding, deleting, and undoing are local DOM changes. storable mirrors the list into local storage, and restore owns page load so a reload keeps what the user added. The GET is an explicit Load the sample list action rather than another on-load race, and the rows arrive with their own delete phrases. The list is an empty <ul> before the first render and after the last delete; the DSL has no conditional empty-state rendering. The template shape is shared with the grow-and-shrink list, while offline fallback covers the failure path.

    The list is empty before the first render and after the last delete; there is no conditional empty-state renderer.
