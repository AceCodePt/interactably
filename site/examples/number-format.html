Format a number or date

formattable formats its value at attach and on every rewrite, handing it to Intl.NumberFormat or Intl.DateTimeFormat with an options object. { type: 'date', dateStyle: 'full' } is a date; anything else is a number. A write through modifiable's set() goes through the formatter.

EUR (de-DE): 0

Show the markup
HTML 
<input id="price" implements="modifiable attributable"
       on-input="#usd.set(this.value); #eur.set(this.value)">
<output id="usd" implements="modifiable formattable"
        formattable-format="{ style: 'currency', currency: 'USD' }">0</output>
<output id="eur" implements="modifiable formattable"
        formattable-format="{ locale: 'de-DE', style: 'currency', currency: 'EUR' }">0</output>

<input id="when" implements="modifiable attributable" value="2026-09-22"
       on-load="#full.set(this.value)" on-input="#full.set(this.value)">
<output id="full" implements="modifiable formattable"
        formattable-format="{ type: 'date', dateStyle: 'full' }"></output>
