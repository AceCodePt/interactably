Order form — the asynchronous seam

on-submit="this.send()" POSTs the form; on-response(html:string) renders the response body into the receipt and reveals it. This site has no backend, so you’ll see the failure path — the alert — which is the honest behavior. Point requestable-url at a real endpoint and the same markup works; the button disables itself via form[aria-busy="true"] button { pointer-events: none }.

<form id="order" novalidate
          implements="prevent-default requestable"
          requestable-url="/api/orders" requestable-method="post"
          on-response(html:string)="#receipt.render({payload: html}); #receipt.show(); #alert.show(false); #order-timeout-alert.show(false); #order-offline-alert.show(false)"
          on-request-error="#alert.show()"
          on-request-timeout="#order-timeout-alert.show()"
          on-request-offline="#order-offline-alert.show()"
          on-submit="#alert.show(false); #order-timeout-alert.show(false); #order-offline-alert.show(false); this.send()">
      <label>Qty
