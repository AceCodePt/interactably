One tab bar, remembered

The three-way intersection in one small widget: storable remembers which tab, revealable flips the panels, and focusable returns focus to the remembered tab on load. The live switch is each button’s on-click; only one button calls this.restore(), and its three on-restore(value:`…`) attributes match the stored literal, so the one phrase for that tab runs and the rest stay quiet. Pick one, reload, and the same verbs run again.

Overview — open because it is the authored default, or because the stored choice said so.

Specs — a stored choice flips it open and returns focus to its tab.

Notes — pick me, reload, and the same three verbs replay.

HTML 
<div class="tabbar">
      <button implements="storable focusable" storable-key="maintab" storable-value="overview"
              on-load="this.restore()"
              on-click="#mp-overview.show(); #mp-specs.show(false); #mp-notes.show(false); this.save()"
              on-restore(value:`overview`)="#mp-overview.show(); #mp-specs.show(false); #mp-notes.show(false); this.focus()"
              on-restore(value:`specs`)="#mp-specs.show(); #mp-overview.show(false); #mp-notes.show(false); #mp-tab-specs.focus()"
              on-restore(value:`notes`)="#mp-notes.show(); #mp-overview.show(false); #mp-specs.show(false); #mp-tab-notes.focus()">Overview</button>
      <!-- Specs and Notes save on click; the one restore site above dispatches their stored value -->
      <button implements="storable focusable" storable-key="maintab" storable-value="specs"
              on-click="#mp-specs.show(); #mp-overview.show(false); #mp-notes.show(false); this.save()">Specs</button>
      <button implements="storable focusable" storable-key="maintab" storable-value="notes"
              on-click="#mp-notes.show(); #mp-overview.show(false); #mp-specs.show(false); this.save()">Notes</button>
    </div>
