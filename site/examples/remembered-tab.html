One tab bar, remembered

The three-way intersection in one small widget: storable remembers which tab, revealable flips the panels, and focusable returns focus to the remembered tab on load. Each button carries an on-click for the live switch and an on-restore for the replay — pick one, reload, and the same verbs run again.

Overview — open because it is the authored default, or because the stored choice said so.

Specs — a stored choice flips it open and returns focus to its tab.

Notes — pick me, reload, and the same three verbs replay.

Show the markup
HTML 
<div class="tabbar">
      <button implements="storable focusable" storable-key="maintab" storable-value="overview"
              on-load="this.restore()"
              on-click="#mp-overview.show(); #mp-specs.show(false); #mp-notes.show(false); this.save()"
              on-restore="#mp-overview.show(); #mp-specs.show(false); #mp-notes.show(false); this.focus()">Overview</button>
      <!-- Specs and Notes repeat the same shape with their own value and receivers -->
    </div>
    <section id="mp-overview" class="tabpanel" implements="revealable" revealable-open="true"><p>…</p></section>
    <section id="mp-specs" class="tabpanel" implements="revealable" hidden><p>…</p></section>
    <section id="mp-notes" class="tabpanel" implements="revealable" hidden><p>…</p></section>
