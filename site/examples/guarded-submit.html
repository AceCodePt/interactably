Validate, then send

validatable × requestable. The guard meets the async seam in one phrase: on-submit="this.validate().send() || #gs-alert.show()". An invalid form stops the chain and the || branch shows the validation alert; a valid one posts, and on-response / on-request-error / on-request-timeout / on-request-offline continue from the element that did the work. This site has no backend, so the server-failure alert is the honest result until you point requestable-url at a real endpoint.

<form id="gs-form" novalidate
          implements="prevent-default validatable requestable"
          requestable-url="/api/signup" requestable-method="post"
          on-submit="#gs-ok.show(false); #gs-alert.show(false); #gs-server-alert.show(false); this.validate().send() || #gs-alert.show()"
          on-response(html:string)="#gs-ok.render({payload: html}); #gs-ok.show()"
          on-request-error="#gs-server-alert.show()"
          on-request-timeout="#gs-server-alert.show()"
          on-request-offline="#gs-server-alert.show()">
      <label>Email
        <input name="email" type="email" required placeholder="you@example.com">
      </label>
      <button type="submit">Sign up</button>
      <p id="gs-ok" implements="renderable revealable" hidden>Signed up — the request landed.</p>
      <div id="gs-alert" implements="revealable" hidden role="alert">Enter a valid email address.</div>
      <div id="gs-server-alert" implements="revealable" hidden role="alert">Couldn't sign up — the request failed.</div>
    </form>
