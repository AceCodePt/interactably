A character counter

length() counts a string in UTF-16 code units — the same unit maxlength uses — so the counter and the platform bound always agree. On a type="number" field it is a not-a-string error, never a digit count. The edge style is an exact-match attribute read — it fires only at the limit.

<textarea id="bio" maxlength="200" implements="attributable"
              on-input="#count.set(length(this.value) + ' of 200');
                        this.setAttr({name: 'data-remaining', value: '' + (200 - length(this.value))})"></textarea>
    <output id="count" implements="modifiable">0 of 200</output>
