A multi-step form, gated on validity

Three sibling forms make one flow: the stepper is a real radio group, and each later radio is natively disabled until the preceding form becomes user-valid. Breaking a form disables every later radio and returns to the broken step. The gate forms listen on change because a committed value is the completion point; field messages listen on input for immediate feedback. The live progress line uses the aggressive valid/invalid pair because it wants the current state on every evaluation. This is a static site with no backend: the final submit only reveals a local confirmation. For the simpler one-input version, see the age gate.
