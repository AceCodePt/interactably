A scroll spy, written out

A current-section indicator — the same thing the docs page’s sidebar does — built with plain HTML and on-intersect. Sections light and unlight their links; the header supplies a measured top margin, and one full view earns a read mark. The observer’s first report handles the first link.

Observe, do not poll

An IntersectionObserver reports when a target crosses an observation box. This page never asks which link is current and never listens to scroll: each section owns the phrases that change its own link, so the relationship stays visible beside the content.

The observer’s first report is an ordinary report. When the opening section is already inside the box, its enter phrase lights the first link without a separate initialization step.

Two sides of one crossing

state:`enter` sets data-visible and state:`leave` removes it. The attribute is the small amount of state the pattern needs; the section, not a scroll handler, decides when it changes.

The sections are tall enough to make the current entry easy to follow. A shorter section can still be observed, of course, but two entries may be lit while the viewport overlaps both.

Start below the header

Every observer uses block-start:`-#spy-header.height`. The reference reads the sticky header’s measured height instead of restating a number, and a resize rebuilds the observer with the new measurement.

The four margin names — block-start, block-end, inline-start and inline-end — are logical sides. The platform exposes physical rootMargin sides, so the library maps them from the element’s writing mode and direction. An omitted margin slot is 0px.

Read the whole thing

When this section is entirely inside the observation box, full:`true` sets data-read on its table-of-contents entry. The once() modifier spends that phrase after the first full view, so the mark stays after the section scrolls away.

full is a boolean slot, not a third state: it fires on every change between fully visible and not fully visible, in either direction. That is why the example uses one true matcher for the lasting mark.

The whole pattern

A sticky header, a table of contents, a handful of sections and a few declarative phrases are all this pattern needs. The browser owns observation, the author owns the markup, and the current entry follows the reader without a page-specific script.
