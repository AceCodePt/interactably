A list you can grow and shrink

render() stamps a template row with an author-supplied id slot, the × button deletes its own row by targeting that id, and undo() removes the last stamped row. The swap animates as a same-document view transition, and on-rendered refreshes count('#dl-list li') once it settles.

HTML 
<button on-click="#list.render({template: #row-tpl, swap: 'beforeend', id: now()})">Add a row</button>
<button on-click="#list.undo(); #count.set(count('#list li'))">Undo last</button>
<ul id="list" implements="renderable" on-rendered="#count.set(count('#list li'))">
  <li id="row-1">
    <input class="item" placeholder="Type in this row">
    <button on-click="#list.render({swap: 'delete', target: '#row-1'})">×</button>
  </li>
</ul>
