A shop with an anonymous cart

This is a static shop with no checkout: the products are HTML on the page, and the anonymous visitor’s cart is kept in local storage. Each click on Add to cart adds one line, so a repeated product is repeated rather than merged. The renderable line and its storable mirror are shared with the to-do list; there is no account, server cart, or quantity control here.
