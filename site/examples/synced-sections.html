Three synchronized sections, written out

Three sections — install, config, troubleshooting — each with its own tab bar. Every button names the three panels it opens, the six it closes, and this.save(). One button per distinct storable-value also carries on-load="this.restore()"; its on-restore(value:`…`) matches the stored literal, so the matching phrase replays that selection across all three sections and no other. The rest only save. Adding a fourth section means editing every phrase; that is the price of push.

npm install ships with Node.

pnpm install is the fast, disk-efficient one.

bun install is the all-in-one runtime.

npm config — .npmrc lives in your home directory.

pnpm config — the store lives outside each project.

bunfig.toml is where bun is configured.

npm troubleshooting — npm cache clean --force clears the cache.

pnpm troubleshooting — pnpm store prune reclaims disk.

bun troubleshooting — bun pm cache rm clears the cache.
