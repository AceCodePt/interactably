Three synchronized sections, written out

Three sections — install, config, troubleshooting — each with its own tab bar. Every button names the three panels it opens, the six it closes, and this.save(); its on-restore repeats the nine show / show(false) receivers without the save, and on-load="this.restore()" replays the stored selection when the page loads. With implements, storable-key, storable-value and two phrases, a button is around a dozen lines — that is the point: this is what a template would emit, and aria-controls on each button is filled in by revealable from the phrase. Adding a fourth section means editing every phrase; that is the price of push.

npm install ships with Node.

pnpm install is the fast, disk-efficient one.

bun install is the all-in-one runtime.

npm config — .npmrc lives in your home directory.

pnpm config — the store lives outside each project.

bunfig.toml is where bun is configured.

npm troubleshooting — npm cache clean --force clears the cache.

pnpm troubleshooting — pnpm store prune reclaims disk.

bun troubleshooting — bun pm cache rm clears the cache.
