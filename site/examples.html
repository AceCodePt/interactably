Examples

Everything below is live, plain HTML: is="interactable-…" hosts, implements, on-* triggers and verbs. Open the console while you click — logger prints from phrases. Each card shows the exact markup it is running.

Price calculator

The total is computed from a formula, format(sum('#list .amount'), { style: 'currency', currency: 'USD' }), re-evaluated by #total.compute() after every change. Press Escape in the field to reset().markClean() — prevent-default derives keydown:escape and cancels the browser’s native revert.

Auto-growing note

auto-grow tracks the content height, dirtyable outlines the field while it differs from the value it connected with, storable persists it to localStorage, and paste-transform collapses runs of whitespace on paste.

Revealable strategies

revealable reads the element: open on <details> and <dialog>, popover state on [popover], and data-open on anything else. Focus trapping, the top layer, light dismiss and Escape handling come with the platform elements for free.

Why not just use hidden?

Because each platform element already exposes its own open state.

A native <dialog>, opened with showModal().
A popover in the top layer, toggled through showPopover().

Validation guard

validate() calls reportValidity() and preventDefault() on failure, which stops the rest of the chain. && continues on completion, || continues only on a guard abort: setAttr runs when the form is valid, the alert shows when it is not. The field uses pattern rather than type="email", so the browser only complains when you submit, not while you type.

Thanks — that address looks valid.

Enter a valid email address.
Show the markup 
<form is="interactable-form" id="signup" novalidate
      implements="prevent-default validatable attributable"
      on-submit="#signup-alert.hide(); this.validate().setAttr({name: 'data-signed', value: 'true'}) || #signup-alert.show()">
  <label>Email
    <input name="email" type="text" pattern="[^@\s]+@[^@\s]+\.[^@\s]+" required placeholder="you@example.com">
  </label>
  <button is="interactable-button" type="submit">Sign up</button>
  <p class="success" hidden>Thanks — that address looks valid.</p>
  <div is="interactable-div" id="signup-alert" implements="revealable" hidden role="alert">Enter a valid email address.</div>
</form>

JSON template

json-template renders a JSON data source through a child <template>, re-rendering when the source changes. {field} interpolates; a nested template carrying data-array repeats per item.

Nested triggers & no-propagate

A click on a button inside a trigger fires both phrases as it bubbles, like nested onclick. no-propagate stops the bubble on the inner element. Open the console to watch logger.

Clicking the plain area logs the outer line.

Show the markup 
<div is="interactable-div" id="outer" implements="logger"
     on-click="#outer.log('outer card')">
  <p>Clicking the plain area logs the outer line.</p>
  <button is="interactable-button" on-click="#outer.log('plain inner button')">Inner button (bubbles)</button>
  <button is="interactable-button" implements="no-propagate"
          on-click="#outer.log('stopped inner button')">Inner button (no-propagate)</button>
</div>

Order form — the asynchronous seam

on-submit="this.send()" POSTs the form; the response swaps into the receipt and requestable-after reveals it. Failures run requestable-error. Point requestable-url at a real endpoint and the button disables itself via form[aria-busy="true"] button { pointer-events: none }.
