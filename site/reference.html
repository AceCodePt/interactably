modifiable

Typed writes; set(...) takes an expression inline, so derived values are computed on the trigger that wants them. set() does not clamp — say the bound: min(#q.max, …).

renderable

any element

Stamps a template with flat scalar slots into text nodes and attribute values, or inserts a payload markup string as-is (the two are mutually exclusive — supplying both is a signature error). undo() reverses the one last render (removes appended rows, restores displaced markup). Every successful swap animates as a same-document view transition and fires rendered when it settles; renderable-disable-view-transition opts out.

requestable

any element

Fetch and announce; never touches the DOM. GET is latest-wins; anything else is first-wins. Failures split three ways: request-error carries the non-ok status (filter with a status literal, on-request-error(status:`401`)), request-timeout fires when requestable-timeout elapses, and request-offline fires when the fetch rejects outright; the last two carry no values. response carries the response body text as html and the status, so on-response(html:string)="#list.render({payload: html, swap: 'beforeend'})" places it.

validatable

form · input · select · textarea

The active guard validate() still calls reportValidity() and preventDefault() on failure. Silent checks use checkValidity() (there is no quiet validate() verb): valid / invalid report every evaluation, while user-valid / user-invalid require both a user interaction and a validity transition; all four events carry no values. The platform has no native valid event (w3c/html#1696). checkValidity() still emits native invalid on failing controls; on fields, our event deliberately shares that name, and if it ever bites the fix is a rename, not a redesign. Aggregate validity belongs on a form, not a fieldset.

storable

input · select · textarea

Persists a declared slot under a declared key to local or session storage — nothing is stored unless a phrase calls save(). storable-value is a literal, or a ref: a bare ref (this, #cart) means the element's contents, this.value means that property. restore() reads the key and fires restore carrying the stored string as its declared value value (on-restore(value:string)), writing nothing to the DOM; the phrase receives the value and decides where it lands, and an on-restore(value:`…`) literal is how it runs for one stored value only. Nothing restores without on-load="this.restore()". clear() removes the key.

copyable

pre · code · p · div

Copies the element’s own text to the clipboard; a button calls it as a plain receiver (on-click="#snippet.copy()"). On success it dispatches copy — which shares the attribute with the native clipboard copy — and copy-error on total failure; empty text is a no-op; it never touches attributes, so the flash is the author’s (on-copy).

Reference grammar

Text 
attribute := 'on-' event-type [ '(' value-decl (',' value-decl)* ')' ]
value     := phrase (';' phrase)*
phrase    := [key ':'] unit (('&&' | '||') unit)*
unit      := ref ('.' (call | modifier))+
ref       := '#' id | 'this'
call      := verb '(' [arg | object] ')'
arg       := number | "'" string "'" | 'true' | 'false' | ref | read | name | expr
read      := ref '.' ('value' | 'checked' | 'min' | 'max' | 'step')
object    := '{' field (',' field)* '}'
field     := name ':' arg
value-decl:= name ':' (tsyntax-scalar | '`' literal '`')
expr      :=    (see the docs)
modifier  := 'debounce(' ms ')' | 'throttle(' ms ')' | 'once()' | 'delay(' ms ')'

Whitespace is insignificant outside string literals. id excludes whitespace, ,, ;, ., (, ). name is an identifier. && and || are top-level unit separators, recognized only outside string literals and argument parens/braces; a phrase may use one of them, never both. Which of arg / object / nothing a call accepts is decided by the verb’s signature, not by the grammar. A parenthesised attribute (on-response(html:string)) declares the values the event carries, resolved by name inside that phrase; the form is written without spaces, and each declared type is a flat tsyntax scalar. The right-hand side may instead be a backticked literal (on-keydown(code:`Escape`)): the phrase runs only when the event’s field equals it, and a declaration is all literals or all types, never mixed.
